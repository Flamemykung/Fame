# นลิน · Portfolio Companion

ผู้ช่วยบุคลิกผู้หญิง ตอบด้วยกฎและสูตรจาก Portfolio Dashboard เท่านั้น ไม่เรียกบริการ AI หรือดึงข้อมูลตลาดเอง
ไม่ต้องล็อกอิน เปิดจากมือถือ/คอมพิวเตอร์และเพิ่มไปยังหน้าจอหลักได้ คำถามและบทสนทนาอยู่บนอุปกรณ์

## ข้อมูลจาก Dashboard

- นลินอ่านเฉพาะข้อมูลบริษัทและตลาดที่ Dashboard โหลดไว้แล้วจากตัวเก็บหลักฐานร่วมกัน ไม่มีตัวอ่านตลาดหรือบริการ AI ภายนอกในเส้นทางคำถาม
- คำถามและปุ่มอ่านข้อมูลใหม่ทำได้เพียงอ่านตัวเก็บหลักฐาน การขอ Ticker ที่ยังไม่มีข้อมูลไม่สร้างงานค้นหาจากผู้ให้บริการ
- เปิด Chart หรือ Info ใน Dashboard เพื่อโหลดข้อมูลใหม่ทันที หลังจากนั้นส่วนข้อมูลของ Dashboard ตรวจราคาทุก 25 วินาที และงบ/ETF ทุก 60 วินาทีสำหรับหลักทรัพย์ที่เปิดดูแล้ว
- ตัวอัปเดตหยุดหลังไม่มีหน้า Dashboard ที่ทำงานอยู่ประมาณ 75 วินาที ไม่เพิ่มหลักทรัพย์ใหม่ตามคำถามของ AI
- แอปออนไลน์ส่งเฉพาะ Ticker/ชนิดข้อมูลที่อ่าน ตัวเชื่อมต่อส่งสำเนาหลักฐานที่ Dashboard มีอยู่ ไม่โหลดผู้ให้บริการเพื่อตอบงานของนลิน
- ถ้าไม่มีข้อมูล ข้อมูลเก่า หรืออัปเดตล้มเหลว จะแจ้งให้เปิดข้อมูลใน Dashboard ก่อน ไม่มี snapshot ตัวเลขเริ่มต้นหรือหุ้นอื่นมาใช้แทน
- ไม่ส่งบัญชี ยอดเงิน ธุรกรรม บันทึกลงทุน หรือฐานข้อมูลพอร์ตส่วนตัว บทสนทนาอยู่บนอุปกรณ์
- แสดงเวลาที่ Dashboard ตรวจและเวลาของราคาแยกกัน ราคาอาจหน่วงหรือเป็นราคาตลาดปิด งบและ ETF เปลี่ยนตามรอบเผยแพร่ ไม่รับรองข้อมูล tick แบบ real time
- API ใช้ no-store และ service worker เก็บเฉพาะหน้าตาแอป

งบใช้รายปีตาม Dashboard หากไม่มีงบไตรมาสจะไม่ใช้รายปีแทน แนวรับ–แนวต้านคำนวณจากข้อมูลรายวันที่มีอยู่จริง พร้อมสูตรและหลักฐาน

## เปิดใช้งาน

เปิด Portfolio Dashboard แล้วเลือก **นลิน · ผู้ช่วย** หรือเปิดลิงก์ออนไลน์จากหน้านั้น
Dashboard เริ่มตัวส่งข้อมูลเบื้องหลังเมื่อมีไฟล์ตั้งค่า `.runtime/assistant-bridge.json` ในโฟลเดอร์ Dashboard
ไฟล์นี้เก็บ URL และ token สำหรับส่งข้อมูล ไม่ถูกเผยแพร่หรือใส่ในแอปฝั่งผู้ใช้
ฝั่ง Site ต้องมี secret `DASHBOARD_BRIDGE_TOKEN` ที่ตรงกัน และ R2 binding `BUCKET` ตาม `.openai/hosting.json`

`knowledge.json` ใช้รายการ Ticker และเอกสารเริ่มต้นเท่านั้น ตัวเลข snapshot ไม่ใช้ตอบคำถามปัจจุบัน
Node preview แสดงหน้าตาแอป ส่วน API ต้องใช้ Site ที่มี R2 และ Dashboard เชื่อมต่อแล้ว
ระบบย้ายไปโฮสต์อื่นที่รองรับ Fetch API และ object storage ได้ โดยต้องตั้งช่องทางรับข้อมูลจาก Dashboard ด้วย

## ตรวจสอบ

```powershell
node --test test_engine.cjs test_live.mjs
node build.mjs
```

จากโฟลเดอร์ `portfolio_dashboard`:

```powershell
python -m unittest test_assistant_snapshot test_assistant_feed test_live_market_data test_dashboard_navigation -v
```

ชุดทดสอบตรวจการใช้ข้อมูลร่วมกับ Dashboard การปฏิเสธข้อมูลที่ไม่มีเวลา/สกุลเงิน ขอบเขตข้อมูลส่วนตัว การยืนยันตัวส่งข้อมูล และการไม่ตอบจาก feed เก่าหรือแหล่งข้อมูลอื่น
